Project overview

Make every layer of analysis feel like part of the same workspace.

Signal BI is a responsive analytics canvas for composing and exploring dashboards. It connects configurable charts, data grids, KPI tiles, filters, and commentary in one extensible product experience.

ProjectSignal BIAnalytics workspace and embeddable Canvas V2
RoleProduct directionUX decisions, design review, and AI-assisted frontend build
FocusComplex workflowsData exploration, configuration, and reusable UI foundations
PlatformResponsive webReact and TypeScript component workbench

The challenge

Rich configuration can quickly turn into a wall of controls.

Analysts need to move from a summary to the details, shape how a visualization works, and understand the effect of each change. The interface has to support that depth without losing orientation or making the preview feel disconnected.

01

Bring tools together

Charts, grids, metrics, filters, and annotations need to work as one coherent dashboard.

02

Keep configuration clear

Show the settings that matter for each widget while leaving room for specialized options.

03

Preserve analyst context

Let people configure, compare, and inspect data without breaking their flow.

Configuration, in context

Three zones create a steady path from settings to preview.

Chart and grid settings share one modal shell. A narrow rail switches settings sections, the center panel handles configuration, and the preview grows into the remaining space. Apply commits the draft; Cancel discards it.

Design decisions

Let the data type and task determine what appears.

01

Adapt controls to the visualization

Chart type determines which dimensions, measures, and display settings are relevant. Specialized options stay available when needed without taking over the entire experience.

02

Give data equal footing with charts

Grids support grouping, pivoting, aggregation, formatting, and sorting as first-class analysis—not just a fallback view.

03

Make the system reusable

Foundations, components, screens, and a typed SDK support consistent evolution from an individual widget to an embeddable canvas.
