# Product screen sources

Ten additional screenshot compositions were captured from interface markup preserved in the original repository: two Metric OS views, three UBA Mobile pairs, two Grounded groups, and three Loop Learning views. Original CSS was retained with isolated capture layout and contrast adjustments. Interface values are sample data, not measured project outcomes.

NAVFlow now also surfaces the existing email ingestion and executive dashboard assets. Finwise and ShiftSnap screenshots were repositioned beside the associated design rationale. IreTV retains its existing screenshots.

Screens are assigned to narrative sections through the optional third field of each project gallery entry. They retain the shared accessible image enlargement dialog.
